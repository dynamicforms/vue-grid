# Accessibility

A grid named with `ariaLabel`, with the filter row and the status bar shown. A screen reader reads it as a table:
the header row, the filter row and 400 records, each record announced with its position in the whole data set, also
for records the grid has not rendered yet. The status bar announces the active filters, the record count and the
selection count when they change.

The sort indicator of each column is a button: Tab to it, then press Enter or Space to sort, Shift+Enter or
Shift+Space to add the column to a multi-column sort. The buttons above the grid hide the filter row and remove all
records, which shows the summary row of an empty grid.
